Project 01 · Featured
NTI Final
Laptop Price Prediction
AI-powered interactive web application that predicts laptop prices from real-world market data. Full ML pipeline including data cleaning, EDA, feature engineering, and model comparison with evaluated performance metrics.
⚠️ Problem
Laptop prices are driven by dozens of noisy, non-linear specs (CPU, RAM, GPU, storage), making manual pricing estimates unreliable for buyers and sellers.
🛠️ Approach
Cleaned and engineered features from raw specs, then benchmarked Random Forest against Linear Regression — chose Random Forest since it captured the non-linear relationships between specs and price far better.
📈 Result
Random Forest outperformed the linear baseline and was deployed as a live Streamlit app giving instant, real-time price predictions.

DEPI Grad Project
Explainable AI Model Debugger
A multi-phase Flask platform, built with a graduation team, that turns opaque ML pipelines into transparent, debuggable systems — from automated EDA and reporting to an interactive visualization layer, with SHAP/LIME explainability planned for later phases.
⚠️ Problem

Project 04
NLP
Resume NLP System
An interpretable NLP pipeline, built with a team, that classifies resumes into job categories, matches them against job descriptions, and generates new job descriptions — deployed as a Streamlit app.
⚠️ Problem
Manually screening resumes against job descriptions is slow, and most matching tools rely on opaque black-box models that are hard to trust or explain.
🛠️ Approach
Cleaning and preprocessing feed a TF-IDF vectorizer; resumes are classified with a centroid-based classifier and matched to job descriptions via cosine similarity.
📈 Result
A fully interpretable, no-black-box matching and classification tool live in a Streamlit app.
